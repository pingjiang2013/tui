# 数理逻辑 · Mathematical Logic

一个零依赖的数理逻辑节点游戏原型。玩家从公共的 `0、1` 出发，沿策梅洛主干构造后继程序，也可以探索保留并集内容的冯·诺依曼分支；主线继续构造关系、公式、公式集、语义后承和自然演绎证明，有限序列作为可选的集合编码路线开放。

## 运行

直接用 Google Chrome 打开 `index.html` 即可。项目不需要安装依赖、构建或启动服务器。

项目目录为 `mathematical-logic`，在线地址：https://pingjiang2013.github.io/tui/mathematical-logic/ 。原来的 `logic-foundry/` 地址保留跳转页。同一网站下的旧存档与显示设置会自动迁移到新名称，不清除旧数据。

## 操作

1. 点击左侧零件，将节点放入工作台。
2. 点击节点右侧的红色输出端，再点击另一个节点左侧的蓝色输入端来接线。
3. 点击画布上的连线可以移除该连接。
4. 拖动节点标题可以整理画布。
5. 把最终结果接入金色目标节点，然后选择“运行构造”。

鼠标悬停端口一秒会显示它的语义名称；点击节点主体会检查该节点当前算出的结果；点击连线可以移除连接。顶部“关卡地图”可以在已解锁路线之间切换。

工作台顶部可以在“数学记法”和“集合编码”之间切换；自然数缩写会服从当前的策梅洛或冯·诺依曼路线，不会混用两种构造。

关卡完成 ID 和当前位置以 v20 JSON 存档保存在浏览器的 `localStorage` 中，解锁状态由关卡前置关系动态计算；已有 v5–v19 存档会自动保留并迁移。

## 原型范围

- 配对、并集族与交集族三个无失败教程，以及 255 个树状关卡；策梅洛路线推进主线，冯·诺依曼路线、变量绑定、归纳方法、可靠性、反模型及完备性元理论等内容形成分支。
- 四关“函数与集合”支线接在自然投影 E7 后：玩家用自己构造的 q 收集两个输入集合的像，再从选定输出集合找齐原像；随后构造 h 与 h∘q 的具体函数图，最后沿已有双射 k 与逆函数 k⁻¹ 完成两个方向的复合，认识恒等函数。观察台以嵌套集合、汇合路径和往返对应呈现结果；像、原像和复合都不作为尚未构造的检查零件进入工具架。
- M5“删去 0，仍然一一对应”接在恒等函数之后，并要求已完成冯诺依曼自然数、自然数次序与归纳集入口。玩家用已有后继和并集族构造任意自然数及任意非零自然数的往返路径，得到 ℕ 与 ℕ∖{0} 的双射；无限集合的存在性作为新增假定明确说明。观察台的有限窗口可切换具体输入，同时展示一般集合论理由；验证按完整路径对全体允许输入的作用进行，不以有限样例宣告定理，也不允许直接连接原输入蒙混通过。
- M6–M8 继续进入可数集合。玩家先构造 0↔a 和 n↔u 的通用推进条款，为 a、{a}、{{a}}、… 编号；再用后继构造 d(0)=0 与 d(S(n))=S(S(d(n)))，完成后才解锁倍增函数；最后用倍增、后继和嵌套有序对给 X×{0,1} 编号。观察台由实际构造展开有限窗口，并说明没有遗漏与重复的一般理由。验证保留任意编号与已有结果的符号含义，不把具体样例碰巧相等当作通用条款成立。
- O3“极小不等于最小”让玩家用 a、b、c 构造两个互不包含的非空集合，收成有两个极小元却没有最小元的 M，再保留它们并加入非空最小元，得到 N。观察台画出集合内部成员、实际包含箭头及新增集合缺少的成员；验证接受不同正确构造。O4 明确回到 O2 的 V 形偏序，再为它增加比较关系。
- 命题模态逻辑从“第一门完整逻辑”处分支，不要求先完成一阶逻辑。L1–L7 分别构造模态公式、世界赋值与可达关系，观察 □、◇ 及嵌套模态；公式形成与语义操作分开。右侧模型持续可见，可点击世界切换判断位置，未知数据不被当作假；无出口世界按 □ 真、◇ 假处理。L8–L13 先给已有命题证明标明世界位置，再从两个规则模式铸造 □E，沿两条可达条件应用它。玩家为 P→□P 构造反模型以后，在任意可达世界内证明合取交换的蕴含，铸造 □I；最后嵌套两个普通假设与一个世界范围，完整证明 K：□(P→Q)→(□P→□Q)。Gentzen 与 Fitch 同步显示世界、临时可达条件及依赖解除。可达条件与对象语言公式、模型中的关系数据分别处理；□I 检查世界名字的新鲜性，不要求外部前提全部为空。已有关卡的存档 ID 保留。
- L14–L18 先对照 □E 铸造 ◇I，再沿 □E、→E、◇I 将可达世界里的 Q 带回出发世界的 ◇Q。第三关用 ◇(P∧Q) 授权临时见证范围，入口提供同一次授权的 wRu、u:P∧Q；玩家分别取得 ◇P、◇Q 并合取，完成后才解锁 ◇E。出口只有一个内层证明输入，解除自己的两条临时依据，保留原来的 ◇A 与其他外部前提。随后玩家在嵌套范围中证明 □(P→Q)→(◇P→◇Q)，最后固定三个世界的 P、Q，只构造关系来反驳 (◇P∧◇Q)→◇(P∧Q)。见证范围的新鲜性、未授权使用、临时名字泄漏与隐式入口依赖环路均有执行检查；Gentzen 与 Fitch 展示同一个范围中的两条临时依据和解除。对偶关系及其他模态系统留到后续。
- L19–L21 从 □P→P 的非空可达反模型进入自反条件。玩家保留原关系 R，亲手收集三个世界自己到自己的有序对，构造 Δ，再以配对和并集族合成 R∪Δ。观察台保留原关系的对照：P 的赋值不变，w₀ 的 □P 从真变假，□P→P 从假变真。最后在明确新增的自反条件下，玩家分别证明 □P→P 与 P→◇P；两条证明共同使用 wRw，并各自解除普通假设。Gentzen、Fitch 区分系统条件与开放公式前提，保留 R 自反，不将结果误称为 K 中的无条件定理；完成后才命名系统 T，不提供 T 公理按钮。
- 无浏览器的模态接线回归验证：运行 `node tests/modal-proof.test.cjs`，覆盖实际构造、临时范围、三类反模型的穷举、自反扩充、系统条件保留与既有命题证明排版；页面交互与视觉效果另由人工测试。
- 完备性第五、六节先由已经铸造的 `=I、=E` 得到闭项上可证明相等的反身、对称与传递性，亲手构造第一个等价类以后才把闭项商集作为论域；随后构造扩充语言的项模型，并以公式结构归纳完成真值引理。最后忘掉 Henkin 辅助常元，得到原语言的模型存在引理与一阶逻辑完备性定理。
- 七关结构基础：三元素集、有序对、笛卡尔积、关系、函数、函数值记号与函数应用。
- 七关有限序列支线，要求先构造函数并完成冯·诺依曼路线；玩家亲手构造第一投影、读取具体位置集合并完成一次追加。
- 逻辑主线从原子公式开始；玩家构造赋值函数，并用有序对集合完整定义合取、否定、析取与蕴含，再把这些函数用于公式树求值并通过切换真值生成真值表。玩家构造公式集、认识语义后承和公式槽以后，会先把具体公式摆到推理横线上认识规则结构，再交替完成 →E、∧E、∧I 的规则铸造与具体应用。综合推导之后，玩家体验临时依赖并铸造 →I，得到第一条无开放依赖的定理；随后接入 ⊥、¬E、⊥E、¬I，并证明 ¬(P∧¬P)。析取证明模块继续让玩家铸造并应用 ∨I₁、∨I₂，通过具体双范围理解分类讨论，再用新增的公式槽 C 抽象出 ∨E；不对称分类应用之后，玩家在嵌套范围中证明 (P∨Q)→(Q∨P)。接着用四关构造并应用经典反证法 RAA，完成双重否定消去。无任务的总装关以完整关卡页面总览公式语言、经典二值语义、自然演绎规则和玩家已经得到的里程碑结果。Gentzen 展示分叉证明树；Fitch 将同一证明编译成前提去重置顶、带全局行号、真实范围边框和精确依据引用的线性证明文档。
- 一阶语法章共十关：先用有序对和三元素集构造 P、Q、R 及其入口数的符号表，再依次构造一元、二元原子公式，自由变量、全称绑定、量词辖域、部分绑定、嵌套全称句子和存在句子。谓词符号只在语法中规定位置，不会在模型建立前被误称为实际关系。
- 模型与语义章共十七关：玩家先把每个一元谓词适用的全部论域对象收成集合，再把 R 解释为二元关系；完整模型关以抽象记录和“杯子与盘子”的日常解释并排呈现此前成果。随后玩家区分命题赋值与变量赋值，亲手构造变量赋值并用一次函数应用得到项的指称；常驻的模型观察台会随每次接线实时显示变量指向、谓词标记、关系边、当前对象对与满足判断，原子满足不引入成员检查或真假电路。量词通过赋值更新展开为可见的逐对象路径，全称要求覆盖每条路径，存在要求选出并高亮见证；最后玩家在关系图与见证路径的同步反馈中构造一个满足 `∀x∃yR(x,y)` 的关系模型。
- 两关“变量与绑定”支线从部分绑定语义处分叉：玩家用两个只在绑定变量上不同的赋值观察合同现象，再获得合同引理的正式陈述。合同引理的结构归纳证明明确留到元理论阶段。
- 六关“代入与易字”主线使用专门的公式树编辑台：玩家先进行朴素逐字换字并亲眼观察变量捕获，再用新鲜变量完成安全易字与手工修复；最后把“跳过绑定目标”和“冲突时先易字”装入正式的无捕获代入，并第一次运行 `φ[t/x]`。
- 六关“项与函数符号”主线先让玩家用有序对和二元素集构造常元 `c`、一元函数符号 `f` 的入口数表，再依次构造 `f(x)`、嵌套项与含复合项的原子公式。玩家随后亲手构造 `cᴹ` 与函数图 `fᴹ`，最后只用既有的变量赋值、函数应用和有序对沿项树求值，不引入整体求值器或成员检查节点。
- 无任务的“无等号一阶逻辑”总装关完整陈列项、公式、模型语义、变量赋值和自然演绎，并明确无等号的一阶逻辑本身已经完整。随后六关等号扩展先在两对象论域上亲手构造全部自环，以此固定等号的模型意义；玩家再构造并求值 `f(x)=c`，从 `x=x`、`c=c`、`f(x)=f(x)` 三个共用项输出的实例铸造 `=I`。接着直接用任意项元记号 `t、u`、元公式 `φ(y)` 和两次无捕获代入铸造 `=E`；具体应用关让玩家在 `R(c,c)` 中分两步选择替换位置，推导 `R(f(x),f(x))`。元公式只用于构造规则模式，不会成为解锁后 `=E` 节点或证明树的第三个输入。
- 六关“从语言到理论”把闭公式当作筛选模型的公理，再用既有配对构造句子集合 `T`。玩家为理论亲手构造模型、穷尽二对象论域上一元谓词的四种解释以观察不可满足，并在十六个 `P、Q` 解释组成的完整网格中认识一阶语义后承。最后从同一组公理出发，用已有量词 flag 与自然演绎规则证明 `∃x(P(x)∧Q(x))`，明确区分 `T⊨C` 与 `T⊢C`，但暂不预设可靠性或完备性。
- 八关“归纳方法”支线先让性质依据 `𝒜(0)` 沿具体后继链逐层传播，再从三个实例中抽出尚待证明的共同框架 `𝒜(n)⇒𝒜(S(n))`。接着玩家确认从 0 到 0 的零步路径，并只用一次已经熟悉的后继 `S`，把一条已到达 `n` 的路径延长到 `S(n)`；完成后才将“从 0 沿 `S` 能到达 `n`”简称为 `𝒜(n)`。玩家还要从 `𝒜(0)`、`𝒜(1)`、具体一步和任意推步中辨认真正足以覆盖整条后继链的两份材料，再亲手构造 4，让观察台把对象构造历史与依据展开历史逐层对齐，而不把归纳方法或“传播”伪装成节点。随后玩家用已经熟悉的 `P、Q、⊥、∧` 构造第一棵正式命名的语法树，区分根、叶、直接子公式和二元构造；同一模板再接回 `f(t)`、`∀xA`、`A∧B`，直接显示归纳假设的数量由构造器的直接输入数量决定。最后玩家构造真实公式 `∀x(P(x)→∃yR(x,y))`，由观察台逐层完成“每棵公式树都是有限的”这一第一次结构归纳应用。有限序列不作为本支线的前置条件；未来的交汇关会把构造历史正式编码成序列。`𝒜` 始终是元层性质位置，不会混入一阶语言。
- 九关“可靠性”元理论支线接在归纳方法之后。玩家先具体应用 `→E` 观察一次真值保持，再构造 `((P→Q)∧P)→Q` 并亲自补全四行真值表以排除反例；随后通过 `∨E` 的两条情况路径理解分支规则的保真结构，并构造一个无 Flag 全称引入会失败的明确模型。之后把满足前提的模型与一棵真实证明树并排呈现，再用两个结论同为 Q、高度分别为 0 和 1 的证明定义证明高度；沿一棵高度为 3 的证明看清归纳结构后，玩家亲手完成任意证明在高度 0 与高度 n+1 时的两段一般论证。观察台将其余规则按真值、范围、量词与等号四类汇总，而不把逐条验证膨胀成重复关卡；最终得到 `Γ⊢A⇒Γ⊨A`。总结关明确只完成从语法到语义的可靠性方向，不提前假定完备性。
- 三关“反模型与相容性”紧接可靠性：玩家先构造一个满足 `T={∀x(P(x)→Q(x))}` 却推翻 `∀xQ(x)` 的具体模型，由可靠性的逆否用法得到不可推导；再为另一理论构造模型，从 `𝔐⊨T` 与 `𝔐⊭⊥` 推出 `T⊬⊥`。总结关明确区分语义侧的可满足与语法侧的相容，记录已经证明的“可满足 ⇒ 相容”，并把反方向保留为完备性的模型存在任务。
- 完备性前四节共十三关。前两节从相容起点、句子枚举与逐句判定构造相容扩张链；第三节先用具体模型展示现有闭项可能无法命名存在见证，再让玩家把新鲜常元条目加入原符号表、亲手构造扩充语言 `L(d)`，并沿证明高度完成统一改名的归纳证明；之后才把见证公理加入理论，明确区分语言扩充与理论扩张，再用已经铸造的量词 Flag 证明见证扩张保持相容。判定与见证随后交替回到真正的 `S₀`。第四节把全部阶段的决定与见证收成极大一致 Henkin 集 `H`，以项模型需要决定真假、为存在句找到对象为核心说明其目的，并将有限证明保证 `H` 相容的论证压缩在同一总结页；最后通过一次真实的 `¬E` 推导获得 `H⊢B⇒B∈H` 的演绎闭包。
