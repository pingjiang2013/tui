# 逻辑铸造厂

一个零依赖的数理逻辑节点游戏原型。玩家从公共的 `0、1` 出发，沿策梅洛主干构造后继程序，也可以探索保留并集内容的冯·诺依曼分支；主线继续构造关系、公式、有限模型和自然演绎证明，有限序列作为可选的集合编码路线开放。

## 运行

直接用 Google Chrome 打开 `index.html` 即可。项目不需要安装依赖、构建或启动服务器。

## 操作

1. 点击左侧零件，将节点放入工作台。
2. 点击节点右侧的红色输出端，再点击另一个节点左侧的蓝色输入端来接线。
3. 点击画布上的连线可以移除该连接。
4. 拖动节点标题可以整理画布。
5. 把最终结果接入金色目标节点，然后选择“运行构造”。

鼠标悬停端口一秒会显示它的语义名称；点击节点主体会检查该节点当前算出的结果；点击连线可以移除连接。顶部“关卡地图”可以在已解锁路线之间切换。

工作台顶部可以在“数学记法”和“集合编码”之间切换；自然数缩写会服从当前的策梅洛或冯·诺依曼路线，不会混用两种构造。

关卡完成 ID 和当前位置以 v14 JSON 存档保存在浏览器的 `localStorage` 中，解锁状态由关卡前置关系动态计算；已有 v5–v13 存档会自动保留并迁移。

## 原型范围

- 配对、并集族与交集族三个无失败教程，以及 40 个树状关卡；策梅洛路线推进主线，冯·诺依曼路线为可选分支。
- 七关结构基础：三元素集、有序对、笛卡尔积、关系、函数、函数值记号与函数应用。
- 七关有限序列支线，要求先构造函数并完成冯·诺依曼路线；玩家亲手构造第一投影、读取具体位置集合并完成一次追加。
- 逻辑主线从原子公式开始；玩家构造赋值函数，并用有序对集合完整定义合取、否定、析取与蕴含，再把这些函数用于公式树求值并通过切换真值生成真值表。
- 地图预留高级序列、数值递归、两种归纳形式、强归纳、良序原理与等价性桥梁等未来锁位。
- 遗传有限集的实际外延计算，而非预录结果。
- 带端口类型检查的通用节点图执行器。
- 隐藏输入测试、失败反例、提示和可展开的底层数学定义。
- 无评分、资源消耗或唯一解限制。
