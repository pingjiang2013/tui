## 计算性能

最终 Node WebAssembly 测试：Attention 暖运行第 95 百分位约 10.3 毫秒；完整小模型训练 20 步约 1.07 秒；一次推理约 11.3 毫秒。使用已有本地运行资源的新 Python 实例初始化约 2.4 秒，不包括浏览器首次联网下载的真实体验。

这些是本机 Node 中的计算计时，**不能证明 Chrome 的首次加载时间、页面响应、手机性能或渲染流畅度**。

## 模型表现与教学边界

检查点由原始种子 42、学习率 0.035、1200 步小批量梯度下降生成，附原创语料、词表、结构、参数、随机状态及来源校验。

固定验证片段损失从约 4.702 变为 4.281；固定训练片段损失约 0.568。训练过程在 200 步时验证损失约 3.238，继续训练后验证表现反而变差。这说明小模型明显记忆训练句式，不能称为通用语言能力。界面同时提供实时评估和语料查看。

神经元实验只更新第一个隐藏节点的两个参数；其余连接固定。二维 Attention 的输入与参数由手工设置，三个教学 Token 按词展示；最终模型则按字符切分。二维局部 Transformer 演示与最终 Pre-LN 模型的归一化位置不同，课程已说明。实际教学是否足够清楚仍需试学。
