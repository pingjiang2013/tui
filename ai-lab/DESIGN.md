# 产品与执行约定

已确认：完整七部分主线分阶段完成；引导步骤为主；Python 教学；关键课程现场编辑执行。

目标用户只需要基本数学与基础编程概念。教学从问题、观察和操作开始，再进入机制、公式和代码。课程不是术语索引；每节课要解释它解决的问题及与最终模型的关系。

数据边界：实时计算、历史记录、手工教学参数和结构示意必须分别说明。计算结果只由 Python 产生，前端不另写预测或梯度算法。保留训练、验证和小语料泛化限制。

首个完整闭环为预测、误差和参数探索；后续依次接入梯度下降、神经网络、文字与概率、Attention、Transformer、训练及生成。完整主线的交付包括 24 节课程、6 个实验室、学习记录与数值测试。

实现结构为单个静态 React 网站和可独立运行的 Python 计算文件。无需账号、后端、付费调用或 GPU。其他 AI 课程分支、多人记录同步和对外部署不在本次实现范围。

验收分别记录：课程完整性、数值正确性、WebAssembly 一致性、构建、真实浏览器和用户试学。程序不能把前几项自动等同于后两项。
